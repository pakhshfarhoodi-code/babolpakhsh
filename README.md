# سامانه پخش و زنجیره سرد بابل (Babol Cold-Chain Distribution)

سامانه جامع، تحت وب و واکنش‌گرای مدیریت فروش، ویزیتوری، انبارداری و پخش مویرگی محصولات منجمد و زنجیره سرد (بستنی، لبنیات، پروتئینی و نوشیدنی).

---

## 🌟 ویژگی‌های کلیدی سامانه

۱. **پورتال سوپرمارکت‌ها (فروشگاه):**
   - مشاهده کاتالوگ دسته‌بندی‌شده کالاها با فیلتر پیشرفته بر اساس برند
   - استپر هوشمند انتخاب تعداد اقلام همراه با کنترل خودکار موجودی قابل سفارش
   - سبد خرید و ثبت فوری سفارش با صدور پیش‌فاکتور
   - مشاهده اطلاعات ویزیتور اختصاصی و امکان تماس سریع

۲. **پورتال ویزیتورها:**
   - **برنامه امروز:** مدیریت سفارشات جاری و صدور برگه بارگیری تجمیعی جهت تحویل به انبار
   - **مشتریان:** دسترسی به پرونده سوپرمارکت‌ها، ثبت سفارش جدید در محل و تاریخچه خرید
   - **گزارشات:** آمار فروش روزانه و ماهیانه و نرخ موفقیت تحویل
   - **عملیات تحویل/عدم تحویل:** ثبت مرجوعی یا واگذاری هوشمند سفارش به ویزیتور دیگر

۳. **پورتال انبار و سردخانه:**
   - تایید و پردازش برگه‌های بارگیری صادرشده توسط ویزیتورها
   - کسر موجودی فیزیکی و آزادسازی رزروها به صورت آنی
   - ثبت کالای جدید و افزایش موجودی انبار همراه با تاریخچه تراکنش‌های ورودی/خروجی

۴. **پورتال مدیریت مرکزی (ادمین):**
   - تعریف، ویرایش و قیمت‌گذاری کالاها
   - مدیریت دسته‌بندی‌ها و برندها
   - پایش جامع سفارشات، گزارشات مالی و تعیین ویزیتورهای هر منطقه

۵. **معماری فنی مبتنی بر داده (Database-First Architecture):**
   - **حالت دیتابیس Supabase (منبع یکتای حقیقت):** در زمان اتصال به Supabase، تمامی اطلاعات عملیاتی (کالاها، سفارشات، ویزیتورها، فروشگاه‌ها، برگه‌های بارگیری و لاگ‌ها) مستقیماً از دیتابیس خوانده شده و هیچ کش کهنه‌ای در LocalStorage نگهداری نمی‌شود.
   - **همگام‌سازی لحظه‌ای (Real-time Sync):** کلیه تغییرات جداول به‌صورت آنی (Realtime)، به همراه رفرش خودکار هنگام بازگشت تب (Visibility Change)، فوکوس پنجره و اتصال مجدد اینترنت، همگام‌سازی می‌شوند.
   - **حالت آزمایشی (بدون اتصال به دیتابیس):** در صورتی که متغیرهای Supabase پیکربندی نشده باشند، سامانه به‌صورت محلی در مرورگر (LocalStorage) اجرا شده و امکان تست فراهم می‌گردد.
   - رعایت استاندارد دسترس‌پذیری و خوانایی (حداقل اندازه متون ۱۲ پیکسل)
   - پشتیبانی کامل از حالت‌های تاریک (Dark Mode) و روشن (Light Mode)

## 🛠️ پیش‌نیازها

- **Node.js** نسخه ۱۸ یا بالاتر
- مدیر بسته‌ی **npm**

---

## ⚙️ متغیرهای محیطی

برای اتصال سامانه به پایگاه‌داده ابری Supabase، متغیرهای زیر در فایل `.env` تعریف می‌شوند:

```env
# آدرس پروژه در سوپابیس
VITE_SUPABASE_URL=https://your-project-ref.supabase.co

# کلید ناشناس عمومی (Anon Key)
VITE_SUPABASE_ANON_KEY=your-supabase-anon-key
```

> **نکته معماری:** در حالت اتصال به سرور، صفحه لودینگ با اسکلتون مانع از نمایش اطلاعات کهنه می‌شود و در صورت بروز خطای شبکه، پیام تلاش مجدد با دکمه اختصاصی نشان داده می‌شود.

## 🚀 راه‌اندازی و توسعه محلی

۱. نصب وابستگی‌ها:
   ```bash
   npm install
   ```

۲. اجرای سرور توسعه (پورت ۳۰۰۰):
   ```bash
   npm run dev
   ```

۳. مشاهده برنامه در مرورگر:
   ```
   http://localhost:3000
   ```

---

## 📦 بیلد و استقرار (Build & Deploy)

برای تهیه خروجی بهینه‌سازی‌شده نهایی جهت استقرار روی سرور یا CDN:

```bash
# بیلد پروژه در پوشه dist
npm run build

# پیش‌نمایش نسخه بیلد شده
npm run preview
```

برای بررسی خطاهای تایپ‌اسکریپت:
```bash
npm run lint
```
