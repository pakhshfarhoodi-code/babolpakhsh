# پایگاه داده سوپابیس - صنایع برودتی فرهودی (Supabase Database)

این پوشه شامل تمامی اسکریپت‌های SQL، توابع RPC، پالیسی‌های امنیت سطحی (RLS)، تریگرها و مهاجرت‌های پایگاه داده است.

---

## ۱. فایل تجمیعی کل پایگاه داده (All-in-One)
- **`consolidated_schema.sql`**: اسکریپت جامع و کامل کل دیتابیس شامل اسکیمای پایه و تمام ۱۰ مرحله ارتقا و توابع تراکنشی. این فایل را می‌توانید مستقیماً در Supabase SQL Editor اجرا کنید تا ساختار و توابع یک‌جا پیاده شوند.

---

## ۲. پوشه مهاجرت‌ها (`supabase/migrations/`)
مهاجرت‌های گام‌به‌گام به ترتیب اولویت زمانی با پیشوند عددی شماره‌گذاری شده‌اند:

1. **`00_supabase_schema.sql`**: جداول پایه (سوپرمارکت‌ها، ویزیتورها، کالاها، دسته‌بندی‌ها، سفارش‌ها، اقلام سفارش، دفتر کل انبار، برگه‌های بارگیری و پالیسی‌های RLS).
2. **`01_auth_fixes.sql`**: اصلاح تریگرهای ساخت کاربر و همگام‌سازی auth با جدول کاربران.
3. **`02_market_test.sql`**: تست داده‌های بازار و مقادیر اولیه.
4. **`03_deletion_cascade.sql`**: قواعد حذف آبشاری امن سفارش‌ها و اقلام بارگیری.
5. **`04_direct_orders_fix.sql`**: اصلاح مدیریت سفارش‌های مستقیم بدون ویزیتور و تخصیص به فاکتور باز.
6. **`05_loading_bills_v2.sql`**: نسخه دوم برگه‌های بارگیری و مدیریت وضعیت‌ها.
7. **`06_return_and_delivery_fix.sql`**: اصلاح تراکنش‌های مرجوعی کالا به انبار و تحویل نهایی.
8. **`07_visitor_invoice.sql`**: توابع پیش‌نویس فاکتور ویزیتور، ثبت اقلام توافقی، تفکیک قیمت ویزیتور و لاگ حسابرسی.
9. **`08_admin_visitor_invoices.sql`**: توابع تایید نهایی ادمین، قفل قیمت‌ها، لغو فاکتور و جدول `invoice_audit_logs`.
10. **`09_warehouse_step_setting.sql`**: تنظیمات مرحله تایید انبار (`require_warehouse_step`) و ترخیص دو مرحله‌ای.

---

## ۳. پوشه توابع Edge (`supabase/functions/`)
توابع سرورلس کمکی سوپابیس در صورت نیاز به پردازش‌های پس‌زمینه.
